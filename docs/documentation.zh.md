# 文档维护规范

[English](documentation.md) | 中文

本页维护文档职责、lesson 写作要求与文档检查说明。按任务选择规范的入口是[贡献指南](../CONTRIBUTING.zh.md#按任务查找规范)。

## 规则归属

一条规则只有一个主要维护位置；已有中英文配对共同构成一个逻辑来源。其他页面可以保留必要的简短提示，但通过链接引用完整要求，不单独增加例外。

| 内容 | 维护位置 | 其他位置的职责 |
| --- | --- | --- |
| 项目目标与范围 | [MVP](../MVP.md) | README 介绍项目并提供入口 |
| lesson 写作与文档职责 | 本页 | 模板提供填写结构，贡献指南提供任务导航 |
| 双语配对、同步确认与记录 | [双语维护](bilingual-maintenance.zh.md) | 写作入口与模板链接该流程 |
| 概念、译名及保留原名的术语 | [术语表](../TERMINOLOGY.md) | 其他文档使用约定，不复制词表 |
| Issue、提交、PR 与合入 | [PR 协作规范](pull-requests.zh.md) | 贡献指南串联操作，Agent 指令提供提醒 |
| Agent 开始工作与讨论约定 | [AGENTS.md](../AGENTS.md) | CLAUDE.md 链接同一文件 |
| 工程经验与历史证据 | [lessons](../README.md#开发经验) | 解释为什么和适用条件；本项目操作链接对应规范 |

模板与检查器是规则的使用方。修改规则时核对它们是否需要同步调整；实现差异需要修复或明确讨论，不能把两套要求同时当作现行规范。讨论草稿与本地操作记录不是现行规则的来源。

## Lesson 写作

使用[中文模板](../templates/lesson.zh.md)或[英文模板](../templates/lesson.md)，保存到 `lessons/`。替换所有 `{{…}}` 占位符，并按[双语维护](bilingual-maintenance.zh.md)补齐另一语言、切换链接与记录。

- 标题直接说明问题或应用场景。
- 正文固定为“问题 → 经验 → 方法 → 案例”四个非空二级章节及对应英文结构；细分内容使用三级标题。先给出可复用的判断，再用底部案例支持，不只复述提交经过。
- 区分 DSH 的实际做法、我们的推断与本项目采用的做法，不直接照搬其当前完整架构或规则。案例可以是有效设计，也可以是失败与修复；不能仅因 DSH 采用就称其有效。
- 案例链接具体提交，链接标签写明提交与改动主题；按需引用该版本的代码、测试或决策记录。说明它们支持什么结论，不补造未记录的动机。
- 验证状态分别说明历史源码核对、本地执行与远程 CI 实际提供的证据；没有执行的部分明确标注。不要求每个案例都复现，也不能用配置文件或静态阅读证明运行成功。

## 修改规则

先按上表找到维护位置，再搜索规则的独特措辞、相关概念及指向它的链接，检查是否存在副本或冲突。更新主要维护位置及其已有译文；按影响调整模板、检查器和使用该规则的内容。入口只负责导航，不重复完整条款。

引用仓库内规范时使用指向文件或章节的相对 Markdown 链接，方便读者跳转和链接检查。移动规则时同时修正入站链接；旧位置可以保留指向新位置的入口。

审阅时从 README、贡献指南或 Agent 指令走一次实际任务路径，确认能找到更新后的规则；再检查旧位置没有留下相互独立的完整定义。链接可解析不等于规则位置正确，重复语义与例外仍需人工审阅。

## 文档检查

在仓库根目录运行以下检查（Python 3.9 及以上，无第三方依赖）：

```sh
python scripts/check_lessons.py
python scripts/check_lesson_pairs.py
python -m unittest discover -s scripts -p 'test_*.py'
```

[工作流](../.github/workflows/docs.yml)在 push、PR 和手动触发时运行上述检查、Markdown 基础格式及本地文件链接和标题锚点检查。[格式配置](../.markdownlint-cli2.jsonc)排除参考克隆和链接到 AGENTS.md 的 CLAUDE.md；链接检查离线执行，不验证外部网址。

lesson 结构检查验证标题、固定章节、案例来源链接、验证状态及模板占位符；双语检查的范围与限制由[双语维护](bilingual-maintenance.zh.md#检查范围)说明。当前检查不能证明来源支持结论、翻译语义正确或命令能执行，也不执行文档示例类型检查或部署网站。第一条经验的[案例](../lessons/docs-example-typecheck.zh.md#案例)同时作为结构与中文锚点检查样本。

远程检查是否成功以对应提交的 Actions 记录为准；必要检查与合入约束见 [PR 协作规范](pull-requests.zh.md#自动检查与启用)。
